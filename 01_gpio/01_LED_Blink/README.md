# LED Blink

## Objectives

- Configure a GPIO pin as a digital output.
- Control the onboard user LED using the STM32 HAL GPIO functions.
- Use a blocking delay to generate a fixed blinking interval.
- Understand the basic structure of the main program loop.
- Verify the program by observing the onboard LED.

## Hardware

- Board: NUCLEO-F446RE
- LED: Onboard user LED LD2
- GPIO: PA5

## Expected Behavior

The onboard user LED repeatedly turns on and off at a fixed interval.
