# Running LEDs

## Objectives

- Configure multiple GPIO pins as digital outputs.
- Control multiple LEDs independently.
- Use arrays and loops to reduce repeated GPIO operations.
- Create a sequential running-light pattern.
- Understand how software delays affect the animation speed.

## Hardware

- Board: NUCLEO-F446RE
- Multiple external LEDs
- Current-limiting resistors
- Breadboard and jumper wires

## Expected Behavior

The LEDs turn on one after another to create a running-light effect.
The sequence repeats continuously.
